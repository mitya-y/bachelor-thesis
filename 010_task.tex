\section{Постановка задачи}
\label{sec:task}

Целью работы является уменьшение времени работы тестов СнК при запуске на \texttt{Verilog} симуляторе за счет ускорения печати вывода.

Для достижения поставленной выше цели необходимо выполнить следующие задачи.
\begin{enumerate}
    \item Изучить и сравнить уже существующие решения, оценить их по итоговой производительности и сложности интеграции и поддержки
    \item Расширить возможности симулятора для переноса логики форматирования вывода вне симулируемого кода
    \item Реализовать библиотеку форматирования с учетом особенностей передачи данных между тестируемым процессором, симулятором и кодом на языке программирования \texttt{C}
    \item Реализовать в тестируемом коде систему печати с поддержкой новой функциональности симулятора
    \item Провести эксперимент и проанализировать полученное ускорение.
\end{enumerate}
