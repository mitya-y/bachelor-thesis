# Тема
Ускорение запуска тестов на `Verilog` симуляторе

# Описание
Код на `Verilog` симуляторе выполняется очень долго относительно других способов запуска тестов, прохождение отдельных тестов может занимать вплоть до нескольких дней.
Ускорение скорости форматирования сообщений и вывода длинных сообщений может способствовать значительному уменьшению времени выполнения тестов, что крайне полезно как для скорости разработки,
так и для учащения периодичности автоматизированного запуска тестов, благодаря чему будет больше результатов для отдельных изменений в коде.

Для этого предлагается перенести логику форматирования строк в симулятор. Рассматривалось несколько идей, в основном примениние печатания логов на основе словарей (как в операционной системе реального времени `zephyr` или библиотеке `defmt`) или же расширение возможностей симулятора.

Первый подход подразумевает дополнительный проход сборки, замену строк форматирования на уникальные индефикаторы с сохранением в словарь и печатный (например, `base64`) вывод аргументов. Этот подход так же требует генерацию кода и преобразование вывода после прохождения теста.

Для второго подхода необходимо расширить блок специальныx `MMIO` регистров, позволяющих тестируемому коду управлять симуляцией (например, выходить из программы с кодом завершения). После реализации такой функциональности исполняемый код тестируемого устройства сможет печатать строчку с `N` аргументов форматирования за `N + 1` операцию. Черновой вариант такого решения дает значительный прирост скорости печати.
