# Тема
Ускорение запуска тестов на Verilog симуляторе

# Описание
Код на Verilog симуляторе выполняется очень долго относительно других способов запуска тестов, прохождение отдельных тестов может занимать вплоть до нескольких суток.
Ускорение скорости форматирования сообщений и вывода длинных сообщений может способствовать значительному уменьшению времени выполнения тестов, что крайне полезно как для скорости разработки,
так и для учащения периодичности автоматизированного запуска тестов, благодаря чему будет больше результатов для отдельных изменений в коде.

Для этого предлагается перенести логику форматирования строк в симулятор, расширив блок специальныx MMIO регистров. После реализации такой функциональности исполняемый код тестируемого устройства сможет печатать строчку с N аргументов форматирования за N + 1 операцию. Черновой вариант такого решения дает значительный прирост скорости печати.
